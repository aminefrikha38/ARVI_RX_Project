# ARVI-RX

ARVI-RX est un prototype pédagogique d’assistant d’analyse de radiographies thoraciques frontales.

Le système permet de déposer une radiographie, de produire une sortie structurée en JSON et d’afficher une classe parmi :
- normal
- suspicion_opacite
- incertain

Ce projet est uniquement pédagogique et ne constitue pas un dispositif médical.
